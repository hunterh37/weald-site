Keyboard shortcuts, file locations, and the settings that change how Weald behaves.

Terminal shortcuts

Terminal bindings are defined in one place in the application, so the embedded terminal, minimal mode, and Overwatch all obey the same table and the on-screen cheat sheet cannot drift from it. Any keystroke that is not listed reaches the shell untouched, which means typing inside vim, claude, or any other program is never intercepted.

KeysAction
⌘TNew terminal
⌘WClose pane, then tab
⌘DSplit the active tab, up to four panes
⌘ZReopen the last closed terminal
⌘[ and ⌘]Previous and next terminal
⌘1 to ⌘9Jump to terminal, nine selects the last
⌘+ and ⌘−Font larger and smaller
⌘0Reset font size

Notable settings

Usage gauge. An optional readout of Claude Code usage, drawn as thin progress lines around the notch on a MacBook that has one, or as a floating pill on a Mac that does not. It reads local transcripts on a short interval, deduplicates messages, aggregates tokens per account, and computes rolling five-hour and weekly windows. Multiple accounts are tracked separately, including switches between them over time.

Battery behavior. Animation and polling can be reduced when running on battery.

Accent color. One store drives the color of the entire interface, including the first-run walkthrough, which recolors as the choice is made.

Terminal appearance. Font and size apply to every pane at once. A monospace font can be selected independently for the rest of the interface.

Companion. Weald can publish a small read-only encrypted snapshot on the local network for a companion iPhone application, paired once by QR code. The snapshot carries usage windows, git and team rollups, and the attention queue. It never carries terminal output, file contents, diffs, prompts, or transcript text, and it exposes no way to run anything on the Mac.
