Feature

Overwatch

Overwatch turns the entire screen into a view of one project's live sessions. Every terminal shown remains a running, typeable shell; the view is a presentation of the sessions, not a summary of them.

Entering and leaving

Overwatch is opened from the menu-bar panel whenever a project is selected. The panel closes and the overlay expands to cover the desktop, and it collapses the same way on dismissal.

The view remembers where it was left. The presented project and the centered session are recorded on every change rather than only at teardown, so the position survives a quit or an unexpected termination. On the next entry, Weald returns to the last project when it still exists, and to the session that was centered, falling back to whichever terminal was most recently in use.

Modes

A dock along the left edge switches the surface between five modes, each bound to a shortcut on the keyboard's bottom row, ordered left to right to match the dock's order from top to bottom.

ModeShortcutPurpose
Operate⌥ZThe live terminals
Plan⌥XBoard and upcoming work
Daily⌥CThe day's activity
Notes⌥VProject notes
Entertainment⌥BAmbient surface

Projects are switched with ⌥1 through ⌥9. Sessions are stepped through with ⇧← and ⇧→, and the surface is dismissed with Esc or ⌘..

File inspector

A file browser occupies the right edge, mirroring the mode dock on the left. A grip hugs the edge, moving the pointer into a narrow hot zone fans the panel out, and leaving retracts it after a short grace delay so that an overshooting cursor does not close it. Clicking the grip pins the panel open. ⌥/ toggles the pinned state and seeds the selection on the first row, so the browser can be driven entirely from the keyboard.

Idle screensaver

Overwatch can present itself when the Mac has been idle. Weald reads the same system-wide input-idle signal the operating system's own screensaver uses, and after a configurable interval between thirty seconds and thirty minutes it opens Overwatch on the most recently used project against an animated backdrop. The first keypress or pointer movement dismisses it.

One rule governs the interaction: Weald dismisses only the presentations it opened itself. An Overwatch session you opened by hand is never taken away from you.

The animation is written to be inexpensive. It is a single canvas capped at thirty frames per second with a fixed element count, drawing analytic functions of wall-clock time rather than running a simulation. Dropped frames cost nothing, and rendering stops entirely when the surface closes.

Instructor mode

An optional setting makes every keyboard shortcut announce itself as a brief chip in the corner of the Overwatch surface, showing both the keys pressed and the action taken. It is intended for demonstrations, pairing, and screen recordings, where the viewer cannot see the keyboard. It is off by default and does nothing when disabled.
